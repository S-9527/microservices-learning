# ADR-0001 · 技术栈与版本选型

- 状态：已接受
- 日期：2026-11-23
- 决策者：AI 助手 + 用户

---

## 1. 背景

环境已安装 JDK 25 (LTS)、Maven 3.9.16、Docker 29.7，用户希望用 Java Spring Boot + Spring Cloud 系统学习微服务，覆盖完整体系。

风险点：

1. JDK 25 是很新的版本，Spring Framework 6（Boot 3.x）内置的 ASM 可能不认识 class file major version 69，导致组件扫描失败。
2. 当前时间已是 2026 年 11 月，Boot 4 / Cloud 5/6 已 GA，网上大量教程仍在讲 Boot 3 / Cloud 2023-2024，配置方式已经变化。
3. 依赖选错版本会导致「pom 写好了但拉不到包」或「启动即报错」。

---

## 2. 验证过程（不靠记忆，靠元数据）

通过 `curl` 直接查 Maven Central 的 `maven-metadata.xml` 与 BOM POM，得到事实：

| 查询 | 结果 |
|------|------|
| `spring-boot-starter-parent` 最新稳定 | 4.2.0（另有 4.1.x、4.0.x 补丁） |
| `spring-cloud-dependencies` 最新 GA | 2026.0.0（对应 Boot 4.2.0） |
| `spring-cloud-dependencies:2025.1.5` 的 `<spring-boot.version>` | **4.0.10** |
| 2025.1.5 BOM 子项目版本 | Gateway 5.0.5 / OpenFeign 5.0.4 / Commons 5.0.5 |
| `spring-cloud-starter-gateway` 在 5.0.5 | **404（不存在）** |
| `spring-cloud-starter-gateway-server-webflux` 在 5.0.5 | 200（存在） |
| `spring-boot-starter-aop` 在 4.0.10 | **404（Boot 4 已移除，只剩 3.x 和 4.0.0-Mx）** |
| `org.aspectj:aspectjweaver` | Boot BOM 管理，版本 1.9.27 |
| Spring Cloud Alibaba 2025.1.0.0 | 官方 README 确认对应 Cloud 2025.1.x / Boot 4.0.x；内置 nacos-client 3.1.1 / sentinel 1.8.9 |
| `mybatis-plus-spring-boot4-starter` | 存在，3.5.18（Boot 4 专用 starter） |
| `mysql-connector-j` | Boot BOM 管理：26.10.0 |
| `micrometer-tracing-bridge-brave` / `zipkin-reporter-brave` | Boot BOM 管理：1.6.9 / 3.5.3 |
| Docker 镜像 tag | nacos v3.1.1 / sentinel-dashboard 1.8.9 / mysql 8.0 / zipkin 3.5 均实测存在 |
| Gateway jar 内 `spring-configuration-metadata.json` | 配置前缀为 `spring.cloud.gateway.server.webflux.*` |

---

## 3. 决策

采用一套「新但已打补丁」的稳定组合：

| 组件 | 版本 |
|------|------|
| JDK | 25 (LTS) |
| Spring Boot | 4.0.10 |
| Spring Cloud | 2025.1.5 |
| Spring Cloud Alibaba | 2025.1.0.0 |
| Nacos Server / Client | v3.1.1 / 3.1.1 |
| Sentinel | 1.8.9 |
| MyBatis-Plus | 3.5.18 |
| MySQL | 8.0 |

具体规则：

1. 父 POM 继承 `spring-boot-starter-parent:4.0.10`，子模块不写 Spring 相关版本。
2. 用 `spring-cloud-dependencies:2025.1.5` 作为 BOM（`type=pom`, `scope=import`）。
3. 用 `spring-cloud-alibaba-dependencies:2025.1.0.0` 管理 Nacos / Sentinel；用 `mybatis-plus-bom:3.5.18` 管理持久层。
4. 网关使用 `spring-cloud-starter-gateway-server-webflux`，配置前缀 `spring.cloud.gateway.server.webflux.*`。
5. AOP 通过显式引入 `org.aspectj:aspectjweaver` 获得（不写版本）。
6. 所有依赖版本由 BOM 管理，**子模块禁止硬编码版本号**（安全补丁升级只改父 POM）。
7. Zipkin Docker 镜像固定 tag `openzipkin/zipkin:3.5`，不用 `latest`。

---

## 4. 备选方案及被拒原因

| 方案 | 被拒原因 |
|------|----------|
| Boot 3.5.x + Cloud 2025.0.x | Spring Framework 6 对 JDK 25 支持不确定；且是旧世代，教程里容易混淆配置写法 |
| Boot 4.2.0 + Cloud 2026.0.0 | 太新（GA 不久），补丁少；学习项目优先稳定 |
| Boot 4.1.x | 处于 2025.1.x 与 2026.0.x 之间的过渡，配套 Cloud 版本不清晰 |
| 硬编码每个依赖版本 | 升级困难，容易产生版本冲突 |

---

## 5. 后果

### 正面

- 编译和启动基于**实测存在**的依赖坐标，不会「pom 写完拉不到包」。
- 用户学到的是 **2026 年当前主流**的 Boot 4 / Cloud 5 写法，不是过时的 Boot 2/3 教程。
- 版本集中在父 POM，后续安全升级只改一处。

### 负面 / 需要注意

- 网上大部分教程的配置前缀对不上（老教程用 `spring.cloud.gateway.*`）。本仓库文档明确标注，见 [05-Gateway](../05-API网关-Gateway.md)。
- Boot 4 移除了不少老 starter，遇到「找不到 artifact」时先查元数据，不要凭记忆写。
- JDK 25 较新，本地 IDE 需支持（IntelliJ IDEA 2025+）。
