# 00 · 学习路线

> 全局路线图。每阶段给出「目标 / 对应代码 / 对应文档 / 验收标准 / 练习」。
> 前置：[README](../README.md) · [AGENTS.md](../AGENTS.md)

---

## 怎么用这份路线图

1. **按顺序推进**，不要跳。微服务难的不是单个组件，而是「为什么需要它」的因果链。
2. 每阶段先读文档，再对照代码，最后做「动手验证」。
3. 卡住时先查 [12-排错](./12-常见问题与排错.md)，仍不行就记入 [questions.md](./questions.md)。
4. 完成一阶段后回到这里把状态从 ⬜ 改成 ✅（这本身就是一个提交）。
